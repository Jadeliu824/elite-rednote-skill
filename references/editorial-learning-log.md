# Editorial Learning Log（复盘经验库）

发布后的经验要反哺下一期，不能只把数据填进 Notion 就完事。这是跨期复用的学习记录，与单条记录的「复盘/结果」互补。

## 每期记录

- 内容样本（选题 + 标题 + 封面方向 + 栏目 + 内容角色）
- 实际表现（数据 + 采集时间窗口）
- 关键变量（标题结构 / 封面类型 / 栏目 / 时长 / 发布时间）
- 得出的经验
- 可信程度（单篇=低；多次复现=中高）
- 下一次测试方案

## 必须区分事实与假设

- **事实**：某篇曝光量低。
- **假设**：封面缺视觉冲击可能是原因。

不能仅凭一篇就断言封面是唯一原因。要写「可能是」，并设计后续测试验证。

## 每期必问（反哺下一期）

- 哪种标题结构更吸点击？
- 哪类封面更容易被打开？
- 哪些栏目更吸引目标读者？
- 哪些内容更被收藏 / 带来更多主页访问 / 商品点击？
- 哪些选题阅读量高但没商业价值？哪些流量低但带来高质量读者？

## 使用规则

每次新内容生产（`workflows/topic-selection.md` 之后、标题/封面之前）先读最近的学习日志，避免重复犯错，并主动提出与日志经验一致的标题/封面测试。
