# ELITE Brand Identity

This is the single source of truth for ELITE color and voice. Every visual or copy decision resolves against this file. If a value appears elsewhere, it is a copy of the value defined here.

## 1. Primary color — Midnight Sky

The fixed primary background color for all ELITE social media visuals.

| Attribute | Value |
|-----------|-------|
| Name | Midnight Sky |
| PANTONE | 20-0195 TPM |
| HEX | `#16151D` |
| RGB | 22, 21, 29 |

A near-black with a faint blue-violet cast. It reads as "deep ink," not "neutral black." Do not swap it for `#000000`, `#111111`, `#191919`, or any other generic dark — the blue-violet undertone is part of the brand.

## 2. Color tokens

Derived from Midnight Sky. Use only these; do not invent new shades.

| Token | HEX | Role |
|-------|-----|------|
| `midnight` | `#16151D` | Primary background. Never changes. |
| `surface` | `#201F28` | Subtle elevated panel / card on the background. Optional. |
| `hairline` | `#2E2D38` | Hairlines, dividers, faint rules. |
| `warm-white` | `#F2EFE9` | Primary text. Warm, never pure `#FFFFFF`. |
| `light-gray` | `#A9A6A0` | Secondary text, supporting copy, meta. |
| `muted` | `#6F6C69` | Captions, footnotes, small labels. |
| `champagne` | `#D4AF37` | **Default accent** (champagne gold). Use sparingly. |
| `silver` | `#C7C5BF` | Alternative accent (metallic silver). Use when gold feels heavy. |

**Accent rules:** the default accent is champagne `#D4AF37`; metallic silver `#C7C5BF` is an alternative for visuals where gold reads too heavy. Accent is for emphasis and small markers — a hairline, a single highlighted phrase, a pillar label. It is never a decorative frame, never a gradient, never a full background. One accent per visual unless the layout explicitly calls for two as a deliberate pairing. When in doubt, use none.

## 3. Visual identity

- Deep, restrained, sophisticated, intellectual.
- Editorial magazine aesthetics, not social-media template aesthetics.
- Strong typographic hierarchy — the headline carries the visual.
- Generous negative space. Empty space is a design choice, not a gap to fill.
- Warm white and light gray typography on Midnight Sky.
- Restrained metallic silver or champagne-gold accents.
- Print-inspired character: ruled lines, small caps or serif kickers, subtle grain — never glossy effects.

**Avoid:**
- Generic AI-generated social media templates (rounded cards, gradients, emoji stickers, drop shadows everywhere).
- Cheap luxury aesthetics (gold foiling, marble textures, crown/laurel motifs, "luxury" stock vibes).
- Excessive decoration of any kind.

## 4. Voice

ELITE speaks as an insider with judgment, not as a curator or a cheerleader.

- **局内人视角 (insider).** First-person access and judgment, not a neutral summary. "我有 access + 判断，帮你补信息差."
- **判断力驱动 (judgment-driven).** 清醒、直接、有棱角. Every piece carries a view the reader can disagree with.
- **信息差 (information gap).** The value is "you get signal you didn't have," not "you get motivation you didn't ask for."
- **具体 > 模糊 > 抽象.** Name names, give numbers, cite times. A specific detail beats a polished abstraction every time.
- **干冷克制.** Dry, restrained humor used occasionally; understatement over exclamation. "这有点难评" style, not "绝了/炸裂/冲".
- **No CTA.** No 私信我 / 评论区聊聊 / 关注我. The content completes itself.
- **No 标题党.** The title states the real claim.

For the full writing rules and the banned-phrase list, see `editorial-guidelines.md`.
