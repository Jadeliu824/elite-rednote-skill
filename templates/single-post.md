# Single Post (Stage 4 output — single image / essay / case study / BIP)

One-image post or a longer essay. Same writing standards, one continuous argument.

```markdown
## 主标题
（≤ 20 字，一个真实的主张，不是口号）

## 开头
（直接进入冲突或问题，不绕）

## 正文
（顺着想下去：一个问题引出下一个问题，空行分节，不"第一/第二/第三"）

## 结尾
（自然收束，不重复开头、不喊口号、不 CTA）

## 类型
单图 / 长文 / 案例研究 / 评论 / 框架 / 构建记录
```
