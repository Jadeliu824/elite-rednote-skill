# Editorial Brief (Stage 3 output)

Fill all six fields before any writing. The central argument is the spine of the piece and the headline.

```markdown
## 目标读者 Target reader
（是谁？已知道什么？在担心什么？）

## 核心问题 Core question
（这篇回答的**唯一**问题）

## 核心论点 Central argument
（对那个问题的回答，表述成一个可以被反驳的主张）

## 编辑角度 Editorial angle
（局内人视角 / 如果是我会怎么做 / 普遍解读漏掉了关键 —— 具体是什么）

## 读者带走 Reader takeaway
（一句话，读者可以拿去用的东西）

## 为什么现在 / 为什么 ELITE
（为什么值得现在关注；为什么 ELITE 是那个该发的人）

## 角度测试
- [ ] So what：值得现在、对这位读者关注？
- [ ] 张力：有可争论之处？
- [ ] 原创性：不是同源的平庸总结？
- [ ] 判断：有"我"的位置？
```
