# Stage 6 — Visual Production（遗产排版）

把写好的内容渲染成轮播图。排版规范见 `references/visual-guidelines.md`；渲染器 `scripts/render_carousel.py` 已恢复旧库设计（logo 顶部 + 金色竖条 + 金色底高亮 + 自动分页）。

## 1. 封面

固定结构（自上而下，space-between 占满）：

1. logo（顶部居中，84px）
2. 来源真图/截图（完整显示不裁剪）
3. 大标题（≤20字，加粗）
4. 作者/来源（次级灰）
5. 底部一段话总结（150-250字）

封面图用**真图**（用户附的 / 人物图 / 实拍图，见 `workflows/cover-concepts.md`），不用抽象水印、不用机房图库照。**封面必须有真图**：缺图时先拿到图再渲染，不放文字占位。

> 发布文案的 `author` / `source` 不带「Day N」等内部计划标记——那是给团队看的，不是给观众看的。

## 2. 正文

把**长文的全部内容**（每个小节 + 每段）写进 `carousel.json` 的 `sections`，渲染器自动分页：

- 小节主题 → 左侧金色竖条标题。
- 段落 → 46px 正文；`**重点**` → 金色半透明高亮（每节 1-3 处）。
- 自动分页填到接近底部，标题不孤立在页尾。

**内容量（强制）**：长文要写够，让分页自然产出**至少 6-7 张**（封面 + 5-6 张正文），**每张都填满**。不为了凑张数而把每张写薄，也不精简内容——先把内容写充实，再让分页去填。

## 3. 写 carousel.json

```json
{
  "slug": "price-vs-value-2026",
  "title": "股价涨，不代表公司变好了",
  "author": "巴菲特 · 高盛 2008",
  "source": "普通人理解资本市场 · Day 4",
  "screenshot": "/path/真图.jpg",
  "summary": "一段话总结",
  "sections": [ { "heading": "两回事", "paragraphs": ["……", "**重点**"] } ]
}
```

## 4. 渲染 + 检查

```
python3 scripts/render_carousel.py carousel.json
```

输出 `~/ELITE/组图/<slug>/` + 桌面副本。检查：每张 2160×2880、正文填到接近底部（内容最低 y > 画布高 70%）、中文正常、无溢出裁剪、无字体替换。有问题改 JSON 重渲，不要改渲染器排版参数（除非用户要求）。
