# Stage 6 — Xiaohongshu Optimization

Optimize the finished piece for search and feed, without sacrificing editorial quality. Platform mechanics are in `references/platform-guidelines.md`; this is the procedure.

## 1. Title

Write for a human first, then check search:

- The title states the real claim (no 标题党).
- The key searchable term appears naturally — never forced if it makes the title worse.
- Keep it tight: the cover headline and the post title must agree with each other and with the content.

## 2. Search keywords

Identify the natural Chinese phrases someone would type to find this insight. Prefer concrete ("创始人 决策 案例") over abstract ("判断力"). List 2-5.

## 3. Description

Write the description as prose, not a tag list:

- First line is the second-most-important sentence after the cover — make it earn the scroll.
- The searchable terms appear once, in the flow of prose.
- No keyword stuffing, no "在评论区告诉我" CTA.

## 4. Hashtags

A small relevant set (3-8), mixing one broad category tag and specific topic tags. No unrelated trending tags, no tag walls.

## 5. Record

Fill `templates/publishing-copy.md`: final title, search keywords, hashtags, and the full description. The output is publishing-ready but still passes Stage 7 (QA) before anything ships.

**Reminder:** search is a tailwind, not the editor. If optimization and editorial quality conflict, the readable, honest version wins.
