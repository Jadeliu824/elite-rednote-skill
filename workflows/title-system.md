# 标题系统（5 方向）

标题不是把主题压短。每次至少出 **5 个不同方向**的标题，各附理由，再选最佳。

## 五个方向

1. **冲突型** — 突出利益冲突、矛盾或代价。
2. **反常识型** — 挑战读者已有认知。
3. **悬念型** — 制造合理的信息缺口（不虚假承诺）。
4. **数字型** — 用真实、可核验的数据体现规模。
5. **读者利益型** — 直接说明这与普通人/投资者/企业有什么关系。

## 每个标题必须说明

- 点击动机
- 目标受众
- 传播优势
- 潜在问题
- 是否准确反映内容（标题不得承诺正文没有的东西）

## 标题红线

- 不用空洞宏大叙事（「时代」「未来」「革命」）。
- 不为点击夸大事实、不滥用数字。
- 不用无信息增量的普通新闻标题。
- 不堆专业术语。
- 标题与封面、正文三者一致。

## 选择

选最佳并说明理由；无明确最佳则留两个备选交用户定。输出填 `templates/title-options.md`，最终标题进 `templates/publishing-copy.md`。

## 反面案例（供对照）

「1.5万亿市值，背后是一张9000亿的账单」——数字有冲击力，但抽象、没说清读者为何关心、没点出冲突。改造方向：点出「客户在拆供应商的台 / 谁在付这笔账」这类冲突。
